# SNAKE '97 🐍

Un Snake rétro, rapide et sans dépendance, pensé pour jouer directement dans un navigateur sur ordinateur.

## Jouer

Télécharge le projet puis double-clique simplement sur `index.html`. Aucun logiciel n'est nécessaire.

Pour le lancer avec un serveur local, tu peux aussi utiliser :

```bash
npx serve .
```

## Commandes

- Flèches, `ZQSD` ou `WASD` : déplacer le serpent
- `Espace` : pause
- `M` : activer/couper le son
- `R` : recommencer
- `Entrée` : jouer

Le meilleur score est conservé localement dans le navigateur.

## Tests

```bash
npm test
```

## Stack

HTML, CSS et JavaScript natif. Aucun framework, aucune pub, aucun tracking.
